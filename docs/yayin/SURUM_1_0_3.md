# 1.0.3 — sürüm notları (AppGallery canlı, Google Play kapalı test)

Kullanıcı (2026-11-21): "canlı versiyon çıkartalım. Yeni eklenen özelliklerde dilleride tamamlayalım. App gallery ile Androide versiyon çıkalım".
Google Play'de üretim erişimi henüz yok (12 test kullanıcısı, 14 günün 6. günü); Play'e 1.0.3 kapalı test (Alpha) olarak gider.

Derleme:
- AppGallery: `KATKAT_ANDROID_VERSION_CODE=4 KATKAT_ANDROID_VERSION_NAME=1.0.3 tools/unity.ps1 build-android-appgallery`
- Play (kapalı test, test reklamlı): `KATKAT_ANDROID_VERSION_CODE=4 KATKAT_ANDROID_VERSION_NAME=1.0.3 tools/unity.ps1 build-android-store-test`

Çakıl/Kürek kodda var ama hiçbir bölümde yok; notlarda geçmez. Gerçek para satın alma kapalı.
